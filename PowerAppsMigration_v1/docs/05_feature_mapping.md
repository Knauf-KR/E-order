# 5. 기존 기능과 신규 앱 대응

| 기존 Python/Excel | 신규 설계 | 보존 여부/차이 |
|---|---|---|
| 사무직/공용/Plant/창고/폐기 시트 | 같은 메뉴 + 단일 마스터의 구분/상태 필터 | 유지. 실제 행 이동 대신 동일 ID 변경 |
| 모든 열·복수 단어·부분 문자열 검색 | 완전 스냅샷 정밀 모드 + 기본 접두어 모드 | 규모별 차이를 명확히 표시. 접두어를 동일 기능으로 주장하지 않음 |
| 위치·종류·만료 필터 | 인덱스된 Text/Boolean/Date 필터 | 유지. 위치 원문과 표준 코드 분리 |
| 만료/30·60·90일/날짜 미등록/정상 | 화면 계산 및 날짜 범위 서버 필터 | 유지. 만료일 당일은 30일 이내 |
| 폐기 만료 알림 제외 | Retired 별도 상태, 날짜 필터는 InUse/Stock만 | 유지 |
| 행 더블클릭·상세 팝업 | 행 선택 → 조회 모달 → 수정 버튼 → 적용 | UX 유지. 별도 OS 창 대신 앱 내 모달/모바일 화면 |
| 기본/사용자·위치/만료/비고 탭 | 같은 탭과 원본 정보 읽기 전용 영역 | 유지. Plant 특수 열 별도 보존 |
| 등록·수정 | AssetWrite Flow → SharePoint 항목 쓰기 | 적용 버튼 1회로 저장. 파일 전체 저장 버튼 불필요 |
| 0.8초 자동 파일 저장 | 변경 적용 시 항목 저장 | 의도적 변경. 타이핑 중 자동 쓰기 대신 검증 후 원자적 항목 업데이트 |
| 원본 파일 3초 감지 | 30초 Refresh 및 수동 새로고침 | 방식 변경. 푸시 실시간이 아님. 편집 스냅샷은 동결 |
| 로컬 해시·잠금 파일 | 서버 ETag + IF-MATCH + 412 충돌 표시 | 강화. 동일 항목 충돌을 원자적으로 거절 |
| S/N 필수·중복 검사 | 동일 정규화 + 서버 SerialKey 고유 제약 | 강화. 기존 중복은 staging 검토. O/0 강제 치환 없음 |
| 저장 전 백업 파일 | SharePoint 버전 이력 + 사내 내보내기/복구 정책 | 대체. 단일 파일 백업 버튼과 같지는 않음 |
| 저장 전 작업 목록 | 편집 내역/미저장 표시 + 업무 이벤트/기본 버전 이력 | 변경. 여러 항목을 한 트랜잭션으로 일괄 커밋하지 않음 |
| 삭제 → 행 비움 | 관리자 논리 삭제 IsDeleted=true | 복구 가능. S/N은 재사용하지 않고 복원 |
| 창고 이동·폐기 | 동일 자산 상태 변경 + 사유 이벤트 | 유지. 이동 시 사용자/위치 변경을 별도로 명시 |
| 중복·정보 누락 점검 | 마스터 HasDataIssues + staging 중복 검토 | 유지. 운영 고유 제약과 과거 중복 보존 분리 |
| 검색 CSV 다운로드 | 내보내기 Flow가 조건/권한/전체 페이지 적용 | 서버 구현 필요. 갤러리에 로딩된 행만 내보내면 안 됨 |
| SAP Excel 선택·S/N 추출·양방향 대조 | 사내 라이브러리 + 배치/결과 목록 | 2단계. 추출/대량 비교 서버 작업 필요, 현재 Canvas 배포 완료 아님 |
| BAT/VBS·Python 설치·절대/상대 경로 | 회사 계정으로 Canvas App URL 접속 | 제거. Excel은 초기 이관/내보내기 용도 |
| 현재 Excel 수식·현황/SN검사 시트 | 정규화 필드·계산 규칙·서버 집계 | 수식 엔진은 이관하지 않음. 원본 값/수식은 보존 |
