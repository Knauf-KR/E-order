# 3. Canvas 화면별 UI 설계

Knauf 로고, #003778 진한 파랑, #0099DE 하늘색, #F06E00 만료 예정, 오류 붉은색을 유지합니다. 원본 PPT 전체 대신 이미 추출된 로고만 사용합니다. `prototype/index.html`은 샘플 데이터 시안이며 Power Apps 실행 결과가 아닙니다.

## 화면과 흐름
| 화면/컴포넌트 | 주요 내용 | 동작 |
|---|---|---|
| scrOverview | 관리 중/만료/90일/창고/점검 카드, 집계 시각 | 서버 요약 항목에서 수량 표시. 카드가 목록 필터로 연결 |
| scrAssets + cmpNavigation | 전체/사무직/공용/Plant/창고/폐기 메뉴, 검색, 위치·종류·만료 필터 | 한 갤러리와 필터 변수를 공유. 업무별 페이지 제목/설명 변경 |
| conDetailModal | 기본/사용자·위치/기간·만료/비고·원본 탭 | 행 선택 → 서버의 값+ETag를 동일 응답으로 읽음 → 조회 모드 → 수정하기 → 적용 |
| scrAssetDetail | 작은 화면의 상세 화면 | 모달 대신 Navigate. 동일한 동결된 편집 스냅샷과 저장 계약 사용 |
| conMoveDialog | 창고 이동/재지급/폐기, 사유 | 같은 자산 ID의 상태 변경. 원본 역할 유지. ETag로 저장 |
| scrQuality | HasDataIssues 마스터 + S/N 검토 staging 별도 탭 | 운영 점검과 이관 중복 검토를 구분. 임의 병합 금지 |
| scrSAP | 업로드 배치, 회계 시트, 결과 카드/필터/다운로드 | 2단계. 처리 중/성공/실패와 기준월·스냅샷 표시 |
| conConflict | 저장 충돌 메시지, 입력 내용 복사 안내 | 최신 값이 기존 입력을 자동 덮지 않음. 다시 열기 전에 미저장 내용 보존 |

Canvas의 팝업은 **앱 안의 모달**입니다. Tk처럼 별도 OS 창을 만드는 것은 아닙니다. 모달 바깥 컨트롤 비활성화, 키보드 포커스 이동/복귀, 스크린 리더 이름, Escape/닫기 시 미저장 확인을 UAT에 포함합니다.

## 공통 컨트롤 이름과 속성
Power Fx 예제는 안정적인 classic Text input/Dropdown/Date picker/Checkbox 속성을 사용합니다. 현대적 외관은 컨테이너·색·간격으로 만듭니다. Modern 컨트롤로 바꾸면 Text/Value/Checked 등 실제 속성을 조정해야 합니다.

| 이름 | 종류/핵심 설정 |
|---|---|
| txtSearch | Text input, DelayOutput=true, HintText="이름 / PC명 / S/N / SAP번호"; OnChange=02 파일 |
| galAssets | Gallery, Items=03 파일; 각 행 OnSelect=06 파일; 자식 클릭은 Select(Parent) |
| lblAssetStatus | Label, Text=04 파일. 색상도 동일 분기. 색만으로 상태 표현하지 않음 |
| ddLocation | Dropdown Items=SortByColumns(ITLocations,"SortOrder",SortOrder.Ascending), Value="Title". OnChange: Set(varLocation,If(Self.Selected.LocationKey="ALL","",Self.Selected.LocationKey)) |
| ddDevice | Items=Table({Code:"",Label:"전체 종류"},{Code:"Laptop",Label:"Laptop"},{Code:"Desktop",Label:"Desktop"},{Code:"Other",Label:"기타"},{Code:"Unknown",Label:"확인 필요"}); Value="Label". OnChange: Set(varDevice,Self.Selected.Code) |
| ddExpiry | Items의 Code=All/Expired/Due30/Due60/Due90/Missing/Retired, 표시명은 전체/만료/30·60·90일 이내/날짜 미등록/폐기. OnChange: Set(varExpiryMode,Self.Selected.Code) |
| tmrRefresh | Duration=30000, Repeat=true, AutoStart=true, OnTimerEnd=05 파일 |
| conDetailModal | Visible=varModalOpen, Fill=RGBA(0,0,0,0.25) 배경 위 흰색 패널 |
| btnEdit | OnSelect: Set(varIsEditing,true). 조회 모드에서만 활성 |
| btnSave | OnSelect=07 파일. DisplayMode=If(varIsEditing && !varSaving,DisplayMode.Edit,DisplayMode.Disabled) |
| btnNew | OnSelect=10 파일 |
| btnClose | varDirty면 확인 모달. 승인 시 varModalOpen=false. Reset으로 입력을 버리기 전에 안내 |

## 상세 편집 컨트롤
공통 DisplayMode=If(varIsEditing,DisplayMode.Edit,DisplayMode.View), OnChange=Set(varDirty,true). 텍스트 입력 Default는 아래 필드 값입니다.

| 탭 | Text input → varEdit 필드 |
|---|---|
| 기본 | txtSerial→SerialNumber, txtSAP→SAPAssetNumber, txtPCName→PCName, txtModel→Model |
| 사용자·위치 | txtUserKOR→AssignedUserKOR, txtUserENG→AssignedUserENG, txtAD→ADAccount, txtLocationRaw→LocationRaw, txtLocationDetail→LocationDetail |
| 지급·비고 | txtLan→LanConnectorRaw, txtConsumables→ConsumablesRaw, txtChecklist→ChecklistRaw, txtRemarks→Remarks (MultiLine), txtActionReason→빈 문자열 (상태 변경 사유) |
| 기간 | txtMonths→Text(varEdit.UsageMonths) |

- ddGroupEdit.Items=Table({Code:"Office"},{Code:"Shared"},{Code:"Plant"},{Code:"Unassigned"}); Value="Code", Default=varEdit.AssetGroup.
- ddLifecycleEdit.Items=Table({Code:"InUse"},{Code:"Stock"},{Code:"Retired"}); Value="Code", Default=varEdit.LifecycleState.
- ddDeviceEdit.Items=Table({Code:"Laptop"},{Code:"Desktop"},{Code:"Other"},{Code:"Unknown"}); Value="Code", Default=varEdit.DeviceType.
- ddAcquisitionEdit.Items=Table({Code:"Acquired"},{Code:"Unacquired"},{Code:"Unknown"}); Value="Code", Default=varEdit.AcquisitionState.
- ddLocationEdit.Items=Filter(ITLocations,SelectableForAsset=true); Value="LocationKey", Default=varEdit.LocationKey. ALL은 선택 불가, Unknown은 선택 가능하게 기준 목록에 등록합니다. 저장 Flow가 유효한 위치 코드인지 재검증합니다.
- chkHasStart.Default=!IsBlank(varEdit.StartDate). dpStart.DefaultDate=Coalesce(varEdit.StartDate,varToday). 체크가 꺼져 있으면 payload는 null입니다. 빈 날짜를 오늘로 바꾸어 저장하지 않습니다.
- chkExpiryExplicit.Default=varEdit.ExpirySource="Explicit". dpExpiry.DefaultDate=Coalesce(varEdit.ExpiryDate,varToday). 체크가 꺼져 있으면 서버가 시작일+개월로 계산합니다.
- lblExpiryPreview.Text=09 파일. 원본 No./시트/행/LegacyMetadata는 읽기 전용입니다.

## 페이지의 필터 설정
공통 초기화는 varSearch="", varExpiryMode="All", varQualityOnly=false입니다. 다른 드롭다운과 변수를 함께 초기화합니다.
- 사무직: varGroup="Office", varLifecycle="InUse"
- 공용: varGroup="Shared", varLifecycle="InUse"
- Plant: varGroup="Plant", varLifecycle="InUse"
- 창고: varGroup="", varLifecycle="Stock"
- 폐기: varGroup="", varLifecycle="Retired"
- 전체: varGroup="", varLifecycle=""
- 점검: 전체 조건 + varQualityOnly=true
- 90일: 전체 조건 + varExpiryMode="Due90" (이미 만료된 자산은 별도 만료 카드)

## 레이아웃
태블릿 landscape, Scale to fit=false, Lock aspect ratio=false. 전체를 가로 auto-layout으로 나누고 좌측 메뉴 약 216px, 나머지는 유연 폭으로 둡니다. 1,100px 미만은 미리보기 패널을 숨기고 모달을 상세 화면으로 전환합니다. 모바일에서는 열을 줄이고 S/N/PC명/상태를 우선 표시합니다.
