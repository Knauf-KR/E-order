# 10. 확인한 Microsoft 공식 문서

확인일 2026-11-17. URL은 기능/형식/제약을 확인하기 위한 근거이며 회사 정보 조회에 사용하지 않았습니다.

1. [Canvas 앱 .pa.yaml 소스 형식](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/power-apps-yaml): 활성 소스 형식, Src 구조, 검토용 추출 파일과 지원되는 외부 편집 경로.
2. [컨트롤 Code view](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/code-view): Studio 생성 코드의 복사/붙여넣기.
3. [Power Platform Git Integration의 Canvas 앱](https://learn.microsoft.com/en-us/power-platform/alm/git-integration/canvas-apps-git-integration): 지원되는 Git 편집 및 개발 환경 검증.
4. [PAC canvas CLI](https://learn.microsoft.com/en-us/power-platform/developer/cli/reference/canvas): pack/unpack deprecated 표시, download 및 SourceCode layout의 현재 문서.
5. [SharePoint 연결·타입·위임](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/connections/connection-sharepoint-online): Text/Boolean/Date 연산과 StartsWith/Choice 제한.
6. [단일 msapp 내보내기/가져오기](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/export-import-single-app).
7. [Canvas 앱 패키지](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/export-import-app-package).
8. [내보내기/가져오기 개요](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/export-import-app).
9. [SharePoint 대량 목록 필터](https://support.microsoft.com/en-us/sharepoint/data-and-lists/use-filtering-to-modify-a-sharepoint-view).
10. [고유 열·목록 관계](https://support.microsoft.com/en-us/sharepoint/lists/data-and-lists/create-list-relationships-by-using-lookup-columns).
11. [Power Fx 오류 처리](https://learn.microsoft.com/en-us/power-platform/power-fx/error-handling).
12. [SharePoint REST 목록 항목·ETag](https://learn.microsoft.com/en-us/sharepoint/dev/sp-add-ins/working-with-lists-and-list-items-with-rest).
13. [공식 v3 pa.yaml JSON Schema](https://raw.githubusercontent.com/microsoft/PowerApps-Tooling/refs/heads/master/schemas/pa-yaml/v3.0/pa.schema.yaml): 예시 구조 검사에 사용. 검사 시의 SHA-256은 validation-report.json에 기록합니다.

선택 프로비저닝/샘플 적재 도구의 PnP.PowerShell은 Microsoft Canvas 소스 형식이 아니라 별도 커뮤니티 도구입니다. 자체 승인 앱 등록·모듈 버전 검토 후 사용합니다.
